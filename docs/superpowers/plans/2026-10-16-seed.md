# Generated seed data — implementation plan

> For agentic workers: executed natively in one session (superpowers:executing-plans), test-first.

**Goal:** `sql/20_seed_generated.sql`: ~300 customers and ~1,500 orders over 182 days, replayed through every rule,
with scripted demo scenarios; generated by `scripts/generate_seed.py`.

**Architecture:** a pure-Python planner (fixed seed) turns reference data into a time-ordered list of events; a
renderer writes each event as one `pg_temp` helper call; the helpers (`scripts/seed_helpers.sql`) do what T1, a
status move, T4 and T3 do. Times are `pg_temp.seed_at(days, minutes)` before the anchor (Sydney midnight on load day).

**Tech stack:** Python 3 standard library + psycopg2 + python-dotenv; PostgreSQL 18 (PL/pgSQL helpers); pytest.

**Spec:** `docs/superpowers/specs/2026-10-16-seed-design.md`
